# 02 — Stakeholder & RACI

## Stakeholder Register

| Stakeholder | Influence | Interest | Engagement |
|---|---|---|---|
| Executive Sponsor | High | High | Decision approvals and milestone reviews |
| Project Manager | High | High | Delivery coordination, reporting, risks and dependencies |
| Process Owner | High | High | Process validation and future-state approval |
| Quality/Compliance Lead | Medium-High | High | Control requirements and quality validation |
| Operations Team | Medium | High | Workflow feedback, UAT and adoption |
| Data/Reporting Owner | Medium | Medium-High | Baseline data and KPI reporting |

## RACI — Major Deliverables

| Deliverable | PM | Sponsor | Process Owner | Quality | Operations | Data |
|---|---|---|---|---|---|---|
| Project Charter | R | A | C | C | I | I |
| Stakeholder Register | R/A | I | C | C | C | I |
| Current-State Process | R | I | A | C | C | I |
| Baseline Metrics | R | I | C | A | C | R |
| Root Cause Analysis | R | I | A | R | C | C |
| Future-State Workflow | R | C | A | R | C | I |
| UAT & Sign-Off | R | I | A | C | R | I |
| KPI Dashboard | R | C | A | C | I | R |
| Project Closure | R | A | C | C | I | C |

**R = Responsible, A = Accountable, C = Consulted, I = Informed**
