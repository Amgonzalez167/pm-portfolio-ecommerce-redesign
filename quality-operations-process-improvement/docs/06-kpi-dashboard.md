# 06 — KPI Dashboard

## Leadership KPI Framework

| KPI | Baseline | Target | Direction | Cadence |
|---|---:|---:|---|---|
| Defect / Error Rate | 8.0% | ≤ 4.0% | Lower is better | Monthly |
| Rework Rate | 15.0% | ≤ 8.0% | Lower is better | Monthly |
| Average Cycle Time | 5.0 days | ≤ 3.5 days | Lower is better | Weekly |
| SLA Adherence | 88% | ≥ 95% | Higher is better | Weekly |
| First-Pass Yield | 78% | ≥ 90% | Higher is better | Monthly |
| Process Compliance | 82% | ≥ 95% | Higher is better | Monthly |

## Dashboard Design

The dashboard should display:

1. Baseline vs. target vs. current performance
2. Trend over time
3. Threshold exceptions
4. KPI owner and source
5. Project benefit summary

## Reporting Governance

The Data/Reporting Owner maintains source data and reporting integrity. The Project Manager reviews trends, escalates exceptions, and uses the dashboard during milestone and leadership reviews.

> **Important:** Values above are hypothetical simulation data for portfolio demonstration only.
