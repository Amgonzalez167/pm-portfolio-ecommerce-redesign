## Executive Summary

This case study demonstrates the project management lifecycle for an e-commerce mobile app redesign focused on reducing cart abandonment from **38% to a target of 22%**. The portfolio is organized around practical PM artifacts that show how scope, risks, dependencies, delivery, quality, and outcomes are managed.

## 🧭 PM Delivery Framework

**Discover → Plan → Deliver → Monitor → Launch → Learn**

- **Discover:** clarify business outcome, stakeholders, scope, and constraints.
- **Plan:** build backlog, roadmap, acceptance criteria, and RAID controls.
- **Deliver:** coordinate sprint execution, dependencies, and stakeholder decisions.
- **Monitor:** report RAG status, risks, issues, blockers, and KPI readiness.
- **Launch:** confirm QA/UAT, release criteria, analytics, and approvals.
- **Learn:** review outcomes and convert lessons into repeatable process improvements.
